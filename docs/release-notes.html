Release Notes

Edge Platforms · Intel® Core™ Processor (14th Gen), Intel® Processor N150, Intel® Processor N250, and Intel® Core™ 3 Processor N355

Introduction

This document provides release-specific information about the Android* 16 Base BSP reference release for Intel® Core™ Processor (14th Gen) (code named Raptor Lake-S Refresh); and Intel® Processor N150, Intel® Processor N250, and Intel® Core™ 3 Processor N355 (code named Twin Lake), running Android* 16 in a bare-metal OS environment.

Note: The versions of the Android Common Kernel and AOSP open-source software components referenced in this release represent the Intel-validated baseline for the platform. Customers are encouraged to evaluate and integrate updates to these open-source components as they become available from the open-source community.

For build and flashing instructions, see the Getting Started Guide.

Intended audience: OSVs and ISVs interested in using the Android* 16 Base BSP Reference Release for Edge Platforms to enable their customers.

Customer support: Contact your Intel representative or submit an issue to premiersupport.intel.com.
