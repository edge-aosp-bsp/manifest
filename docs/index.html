Audience

Who Should Use This BSP

This BSP reference release supports stakeholders across the Android edge device ecosystem, from hardware design and platform enablement to operating system integration and application development.

OEM / ODM

Original Equipment Manufacturers (OEMs) and Original Design Manufacturers (ODMs) use this BSP as the foundation for developing Android-based edge devices. They define product requirements, customize hardware platforms and peripherals, integrate firmware, and optimize the BSP for specific board designs and product SKUs.

ISV (Independent Software Vendor)

ISVs develop and deploy Android applications and solutions on supported platforms, including point-of-sale (POS), kiosk, digital signage, retail, and edge computing workloads.

OSV (Operating System Vendor)

OSVs build, customize, and maintain Android operating system distributions based on this BSP. Their work typically includes device management integration, over-the-air (OTA) update frameworks, security enhancements, policy management, long-term maintenance, and commercial productization.
